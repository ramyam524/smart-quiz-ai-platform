
# 🧠 Smart Quiz AI Platform - AI Proctoring + Voice + Blockchain
> Built by Ramya M | BTech AI Project

### 🚀 Live Demo: https://github.com/ramyam524/smart-quiz-ai-platform

**An AI-powered online exam system that solves cheating in online exams.**

### ✨ Features That Make It Special:
- 🎤 **Voice Quiz** - Answer questions by speaking (Web Speech API)
- 👁️ **AI Proctoring** - Detects tab switching & face absence
- 📊 **Real-time Dashboard** - Score, time, analytics
- 🔗 **Blockchain Certificate** - Tamper-proof certificate with Hash
- ⏱️ **Auto Submit** - Timer based auto submission

### 🛠️ Tech Stack:
`Python` `Flask` `JavaScript` `HTML5` `CSS3` `AI/ML`

### 📸 How It Works:
1. User starts quiz → AI Proctoring ON
2. Answers via voice or click
3. System detects cheating
4. Score → Blockchain Certificate Generated
